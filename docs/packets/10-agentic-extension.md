# 10/11 Agentic extension

This repo contains a local agent pack: a skill, a subagent note, an MCP server, a hook that blocks a long digit run, a small custom agent, and a permissions note. The pack reads the local decline plate at `http://127.0.0.1:8001/plates`. It does not copy the Fault Plate pack, does not POST the plate, and does not deploy itself or the Grafana server to Render.
